## Описание проекта
To-Do List, перенесенный на Vue 3 с использованием Composition API и сборщика Vite. Компоненты разделены по функциям, используются `props` и `emit`.

## Применение Vue
- **`computed`**: используется для фильтрации задач по поисковому запросу (`filteredTasks`) и разделения на активные/выполненные.
- **`watch`**: 
  1. Следит за массивом `tasks` и автоматически сохраняет его в `localStorage` при любом изменении.
  2. Следит за темой (`theme`) и обновляет атрибут `data-theme` на `<html>`.
- **`v-if`**: используется для условного рендеринга сообщений «Активных задач нет» и «Выполненных задач нет», а также для управления открытием модального окна.
